## 本次改动

- Windows Baseline 工作流为分支改动提供只读构建与测试，不创建 Release；原发布流程改为只在版本标签触发。
- 沿用已验证的 Flutter 3.41.5 与 windows-2022；这是已成功的工具链组合，不宣称它是唯一兼容组合。
- 显式生成应用和 Chewie 本地化，检查登录相关类型与编译错误，运行登录回归和最后一次全套 Flutter 测试。
- 新验证码回归通过真实输入框确认尾部宽度、可输入区域、文字输入及刷新操作；标题测试确认视觉中心位置。
- CI 在隔离工作目录中暂时加载两个历史错误输入布局以及旧标题布局，确认新测试确实因行为断言失败，再恢复已修复来源。这是历史回归敏感度验证，不重新发布错误程序。
- 便携 ZIP 打包入口校验运行文件与 SQLite 来源，写入 BUILD-PROVENANCE.json 和 SHA256。拒绝覆盖已有打包输出，防止混入旧文件。

## 验证边界

打包契约测试使用合成文件验证 ZIP、来源记录和校验值，不声称合成文件能运行。Flutter 测试在 Actions 上执行；本地没有安装 Flutter，本次不要求用户安装本地工具链。

实际 Windows 验收需要从本次 Actions 产物解压到独立目录，确认窗口、完整验证码、输入、刷新和相关登录入口。自动化回归与历史用户对 v2.5.3 的认可不能替代本次产物验收。
