## 验证边界

首次全套测试在既有 v2.5.3 来源发现 17 项失败（793 项通过）：旧设计尺寸和源码结构断言未随改版同步、两项检查假定 LF 换行、Section 测试没有初始化生产中已有的 Chewie 根上下文。经现有源码、失败日志与 `58bdea9` 提交核对，只更新测试断言及测试宿主；点击、输入、大字体布局、滚动和颜色对比度检查继续保留。工具栏测试现在检查渲染图标与点击范围，而非可为空的构造参数。未修改生产 Dart 行为。

打包契约测试使用合成文件验证 ZIP、来源记录和校验值，不声称合成文件能运行。Flutter 测试在 Actions 上执行；本地没有安装 Flutter，本次不要求用户安装本地工具链。

实际 Windows 验收需要从本次 Actions 产物解压到独立目录，确认窗口、完整验证码、输入、刷新和相关登录入口。自动化回归与历史用户对 v2.5.3 的认可不能替代本次产物验收。
